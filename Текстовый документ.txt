
0. Введение

В современную цифровую эпоху веб-ресурсы стали основным источником обмена кулинарным опытом. Существующие платформы часто перегружены рекламой или сложным интерфейсом. Актуальность данного проекта заключается в необходимости создания легковесного, быстрого и отзывчивого веб-приложения для публикации рецептов, адаптированного под требования конечного пользователя. Целью работы является закрепление навыков проектирования реляционных баз данных с использованием MS SQL Server и построения асинхронных серверных систем на базе FastAPI.

1. Теоретическая часть


1.1 Техническое задание на разработку ПП

Настоящее ТЗ определяет требования к созданию веб-приложения «Кулинарный архив». Назначение программы — предоставить пользователям удобный интерфейс для ведения собственной базы рецептов и взаимодействия с сообществом. Программный продукт должен функционировать в клиент-серверной архитектуре и обеспечивать доступ через стандартные веб-браузеры (Chrome, Firefox, Safari).

1.2 Организация ввода-вывода и пользовательского интерфейса

Интерфейс спроектирован на основе принципов SPA (Single Page Application) либо адаптивного рендеринга.
• Ввод данных: Осуществляется через веб-формы (регистрация, создание рецепта с динамическим добавлением шагов и ингредиентов, отправка текстового комментария, клик по звездам рейтинга). Для передачи файлов (изображений блюд) используется тип кодирования данных multipart/form-data.
• Вывод данных: Отображение информации в виде динамических карточек рецептов, списков комментариев и интерактивных кнопок (добавление в избранное в один клик). Обмен данными между клиентом и сервером происходит в формате JSON посредством асинхронных HTTP-запросов (REST API).

1.3 Описание предметной области

Предметная область включает в себя концепции кулинарии и социального взаимодействия. Ключевые объекты:
• Пользователь (User): Физическое лицо, прошедшее регистрацию. Может обладать правами автора или обычного читателя.
• Рецепт (Recipe): Описание приготовления блюда, содержащее название, текстовую инструкцию, время приготовления, калорийность, автора и дату публикации.
• Ингредиент (Ingredient): Элемент состава блюда (например, соль, мука, молоко) с указанием единицы измерения и количества.
• Комментарий (Comment): Текстовый отзыв пользователя к конкретному рецепту.
• Оценка (Rating): Числовое выражение качества рецепта от 1 до 5 звезд.
• Избранное (Favorite): Связующая таблица для формирования персональной книги рецептов пользователя.

2. Специальная часть


2.1 Выбор и обоснование языка программирования

Для реализации серверной части выбран язык Python. Критерии выбора:
1. Высокая скорость разработки благодаря лаконичному синтаксису и богатой экосистеме библиотек.
2. Поддержка асинхронности (asyncio), что критически важно для высоконагруженных веб-приложений.
3. Наличие мощных инструментов для работы с базами данных (SQLAlchemy) и валидации данных (Pydantic).

2.2 Выбор стиля, средств и методов программирования

• Стиль: Комбинация объектно-ориентированного (ООП) стиля для описания моделей данных и сервисного слоя, а также функционального стиля для написания эндпоинтов маршрутизации.
• Средства (Фреймворк): FastAPI. Он выбран из-за встроенной автоматической генерации документации Swagger/OpenAPI, высокой производительности (сравнимой с Go и NodeJS) за счет поддержки ASGI, и строгой типизации данных.
• Методы: Использовался паттерн проектирования Repository/Service для разделения бизнес-логики и логики прямого доступа к СУБД MS SQL Server. Асинхронное подключение реализовано через драйвер aioodbc или asyncpg/pyodbc совместно с ORM SQLAlchemy.

2.3 Описание программы

Архитектура приложения разделена на модули:
• main.py — точка входа, конфигурация приложения FastAPI и подключение middleware.
• database.py — настройка пула соединений к MS SQL Server и фабрики сессий (async_sessionmaker).
• models.py — декларативные ORM-модели для СУБД.
• schemas.py — Pydantic-модели для валидации входящих POST/PUT-запросов и сериализации ответов.
• routers/ — папка со скриптами маршрутизации (разделенные по логике: auth.py, recipes.py, comments.py).

2.4 Описание сущностей базы данных

1. Пользователь: Хранит уникальный ID, имя пользователя, email и хэшированный пароль.
2. Рецепт: Связан с пользователем связью «один-ко-многим» (один пользователь может создать много рецептов).
3. Комментарий и Оценка: Связывают пользователей и рецепты («многие-ко-многим» с дополнительными атрибутами — текст, оценка).
4. Избранное: Чистая таблица связи «многие-ко-многим» между Пользователем и Рецептом.

4.2 Интерфейсная схема программы

Маршрутизация приложения (Sitemap / API Endpoints):
• /auth/register и /auth/login — Регистрация и получение токена доступа.
• /recipes/ (GET, POST) — Получение списка рецептов и создание нового.
• /recipes/{id} (GET, PUT, DELETE) — Просмотр конкретного рецепта, его обновление или удаление.
• /recipes/my (GET) — Вывод списка рецептов текущего авторизованного пользователя.
• /recipes/favorites (GET, POST, DELETE) — Просмотр, добавление рецепта в избранное и его удаление.
• /recipes/{id}/comments (POST) — Отправка комментария.
• /recipes/{id}/rate (POST) — Выставление оценки.

4.4 Руководство программиста

Для развертывания проекта необходимо:
1. Клонировать репозиторий проекта.
2. Установить зависимости: pip install fastapi uvicorn sqlalchemy pyodbc pydantic passlib PyJWT.
3. Настроить строку подключения в файле .env: DATABASE_URL=mssql+pyodbc://user:password@localhost/recipes_db?driver=ODBC+Driver+17+for+SQL+Server.
4. Запустить локальный сервер разработки командой: uvicorn main:app --reload.
5. Интерактивная документация станет доступна по адресу http://127.0.0.

4.5 Руководство оператора

Для работы с системой через веб-интерфейс:
1. Откройте браузер и перейдите по адресу развернутого приложения.
2. Пройдите процедуру регистрации и войдите в систему под своей учетной записью.
3. На главной странице доступен просмотр рецептов. Для добавления рецепта нажмите «Добавить рецепт» и заполните поля.
4. На странице просмотра любого рецепта вы можете написать текстовый комментарий или нажать на звездочки рейтинга для фиксации оценки. Кнопка «В избранное» добавит рецепт в вашу персональную вкладку.

4.6 Пользовательские экраны

В рамках интерфейса реализованы следующие макеты веб-страниц:
1. Экран авторизации: Форма ввода логина/пароля.
2. Главная страница (Лента): Сетка с карточками рецептов (миниатюра, название, средняя оценка, имя автора).
3. Карточка детального просмотра: Полный текст рецепта, список ингредиентов, блок для отправки и чтения комментариев.
4. Личный кабинет оператора: Переключатель между вкладками «Мои рецепты» (созданные пользователем) и «Избранное» (сохраненные рецепты других авторов).

4.8 Текст программы

(Пример ключевого файла routers/recipes.py для демонстрации архитектуры FastAPI)
python
from fastapi import APIRouter, Depends, HTTPException, status
from sqlalchemy.ext.asyncio import AsyncSession
from typing import List
from database import get_db
import models, schemas, auth

router = APIRouter(prefix="/recipes", tags=["Recipes"])

@router.post("/", response_model=schemas.RecipeResponse, status_code=status.HTTP_201_CREATED)
async def create_recipe(recipe: schemas.RecipeCreate, db: AsyncSession = Depends(get_db), current_user: models.User = Depends(auth.get_current_user)):
    db_recipe = models.Recipe(**recipe.dict(), user_id=current_user.id)
    db.add(db_recipe)
    await db.commit()
    await db.refresh(db_recipe)
    return db_recipe

@router.get("/my", response_model=List[schemas.RecipeResponse])
async def get_my_recipes(db: AsyncSession = Depends(get_db), current_user: models.User = Depends(auth.get_current_user)):
    result = await db.execute(select(models.Recipe).where(models.Recipe.user_id == current_user.id))
    return result.scalars().all()

@router.post("/{id}/favorites")
async def add_to_favorites(id: int, db: AsyncSession = Depends(get_db), current_user: models.User = Depends(auth.get_current_user)):
    favorite_entry = models.Favorite(user_id=current_user.id, recipe_id=id)
    db.add(favorite_entry)
    await db.commit()
    return {"message": "Рецепт добавлен в избранное"}
Используйте код с осторожностью.
